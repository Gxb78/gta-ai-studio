# Données locales

Ce répertoire est créé à l’installation et reste ignoré par Git, à l’exception de cette documentation et des marqueurs de dossier.

```text
inbox/       fichiers entrants
projects/    artefacts par projet
library/     médias réutilisables appartenant à l’utilisateur
cache/       résultats recalculables
temp/        écritures temporaires par job
backups/     sauvegardes configurées
datasets/    futurs jeux de données annotés
```

Ne jamais placer de secret dans ces dossiers. La suppression d’un projet devra distinguer artefacts, cache et sauvegardes.
