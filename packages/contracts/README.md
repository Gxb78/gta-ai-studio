# Contracts

Contrats de frontière versionnés partagés par l’interface, l’API et les workers. La représentation TypeScript est dans `src/`; le miroir Pydantic est dans `python/`.

Ces modèles décrivent des données. Ils n’appellent aucun fournisseur, n’accèdent pas au système de fichiers et n’implémentent pas le pipeline.
