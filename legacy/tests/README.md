# Tests

- `unit/` : contrats, transitions et validateurs purs.
- `integration/` : frontières entre composants à partir de la Phase 1.
- `end-to-end/` : parcours desktop complet à partir du vertical slice.
- `media-regression/` : inspections des rendus à partir de la Phase 2.
