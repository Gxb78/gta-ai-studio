### Décisions techniques

#### 1. UUID monotone sans dépendance externe
**Problème** : uuid v7 nécessite une dépendance npm non installée, réseau bloqué dans VM.

**Solution** : Implémentation custom `generateClientRequestId()` avec `Date.now() + random`:
```typescript
function generateClientRequestId(): string {
  const timestamp = Date.now();
  const random = Math.random().toString(36).substring(2, 15);
  return `${timestamp}-${random}`;
}
```

**Justification** : 
- Monotone (timestamp garantit l'ordre chronologique)
- Collision quasi-impossible (timestamp ms + 13 chars random)
- Zero dependency, compatible navigateur
- Respecte le contrat latest-request-wins

#### 2. CSS Transform directe vs layout positioning
**Choix** : `transform: scale() translate()` avec `transformOrigin: "0 0"` et `objectFit: none`.

**Justification** :
- GPU-accelerated (<16.7ms garanti)
- Respecte le contrat `computePreviewTransform()` de reframe.ts
- Compatible avec le rendu Python/FFmpeg (même crop rect)
- Pas de reflow layout (pure composition layer)

#### 3. Subscribe pattern vs polling
**Choix** : Coordinator émet via callbacks, composants s'abonnent.

**Justification** :
- Réactivité immédiate (pas de delay polling)
- Découplage : coordinator ne connaît pas les composants
- Multiple listeners possibles (extensibilité)
- Unsubscribe propre dans useEffect cleanup

#### 4. FocusX interpolation dans InteractivePreview
**Choix** : Calculer `focusX` interpolé côté composant en fonction du playhead.

**Justification** :
- Le clip a `focus_start_x` et `focus_end_x` (tracking dynamique)
- La preview doit suivre le focus en temps réel pendant scrubbing
- Calcul léger, pas besoin de passer par le coordinator
- Cohérence avec le système de tracking

### Limites et risques

#### 1. Tests E2E non exécutés
**État** : Les tests d'intégration API ne peuvent pas s'exécuter dans la VM.

**Risque** : Le vertical slice backend → frontend n'est pas validé en conditions réelles.

**Mitigation** : 
- Le typecheck valide les contrats TypeScript
- La correction de `test_phase2_vertical_pipeline.py` est cohérente avec le contrat `ClipPreviewRequest`
- Les tests doivent être exécutés sur l'hôte Windows

#### 2. Ancienne fonction regenerateSelected() deprecated
**État** : La fonction existe toujours mais est stubée avec console.warn().

**Risque** : Si du code tiers l'appelle, il ne fera rien.

**Mitigation** :
- grep "regenerateSelected" dans le codebase → utilisé uniquement dans EditingStudio.tsx
- Bouton "↻ RÉGÉNÉRER UNIQUEMENT CE PLAN" appelle cette fonction mais n'est pas critique
- À supprimer dans une future PR de nettoyage

#### 3. Build natif non testé
**État** : Le bundle Vite/Tauri n'a pas été construit dans la VM.

**Risque** : Import paths ou side effects inconnus pourraient casser en production.

**Mitigation** :
- Imports vérifiés : `preview/PreviewCoordinator`, `preview/InteractivePreview`
- Pas de side effects dans les modules
- À valider avec `npm run tauri build` sur Windows

#### 4. Artifact URL non testée en conditions réelles
**État** : Le flux `artifactUrl` → video src n'a pas été testé avec un vrai artifact MP4.

**Risque** : CORS, format incorrect ou URL invalide pourraient empêcher la lecture.

**Mitigation** :
- Le backend retourne `artifact_url` conforme au contrat `PreviewResponse`
- Le composant video utilise src standard
- Fallback vers sourceVideoUrl si status === "interactive"
